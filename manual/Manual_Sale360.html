SALE360

PDV Inteligente — O PDV que nunca para, mesmo sem internet

Este manual cobre todos os recursos e funcionalidades do Sale360 — do primeiro login à operação diária de vendas, controle de estoque, compras e indicadores de performance.

Versão 1.0 · Maio 2026 · www.jvptecnologia.com.br

Visão Geral

O Sale360 é uma plataforma SaaS completa para PDV (Ponto de Venda) e gestão de loja. Ela integra vendas presenciais, catálogo online, controle de estoque com rastreamento por lote (PEPS), compras com precificação automática, fornecedores, clientes, cupons e indicadores de performance — tudo em um único sistema acessível pelo navegador.

🛒
PDV Completo
Tela de vendas rápida com busca, carrinho e finalização em segundos. Modo balcão e tela cheia.
📦
Estoque Inteligente
Rastreamento por lote (PEPS), baixa automática na venda, alertas de estoque mínimo.
💰
Precificação Automática
Calculadora de preço de venda com 5 variáveis: custo, custo operacional, taxa cartão, margem e preço final.
📱
Responsive + PWA
Funciona em celular, tablet e desktop. Instalável como app pelo navegador.
🌐
Catálogo Online
Página pública personalizada para cada loja. Clientes navegam e compram pelo WhatsApp.
📊
Indicadores em Tempo Real
Dashboard de vendas, ticket médio, giro de estoque, margem por produto e muito mais.

Arquitetura do Sistema

O Sale360 é composto por:

  • Painel Web (Next.js 16) — Interface de administração e PDV acessível pelo navegador
  • API (Fastify + TypeScript) — Backend único com rotas organizadas por domínio
  • Banco de Dados (PostgreSQL 17) — Persistência de todos os dados com Prisma ORM
  • Catálogo Online (Next.js) — Vitrine pública do lojista com link para WhatsApp
  • Nginx — Proxy reverso com SSL automático

Princípios de Design

  • Mobile-First — Design pensado para celular, expandido para desktop
  • Menos Cliques — Toda ação deve ser completada em até 2 toques
  • Offline-First — O PDV nunca para, mesmo sem internet (modo offline com sincronização)
  • Zero Surpresa — Preço fixo, sem comissão por transação, sem contrato de fidelidade

Acesso ao Sistema

Login

Acesse o sistema pelo navegador na URL fornecida pelo administrador. A tela de login solicita:

  • E-mail — cadastrado pelo administrador da plataforma
  • Senha — definida no primeiro acesso
Primeiro acesso: Sua senha inicial é fornecida pelo administrador. Altere-a imediatamente após o primeiro login nas configurações de perfil.

Após o login, se você tiver acesso a múltiplas lojas, o sistema exibe a tela de seleção de loja. Caso contrário, vai direto para o Dashboard da sua loja.

Seleção de Loja

Usuários com acesso a mais de uma loja podem alternar entre elas sem precisar fazer novo login. Cada loja tem seu próprio:

  • Catálogo de produtos e variações
  • Estoque por lote (PEPS)
  • Histórico de vendas e compras
  • Base de clientes e fornecedores
  • Indicadores e configurações

Sessão e Segurança

  • A sessão é mantida por 7 dias via JWT com refresh token
  • Após expiração, o sistema redireciona para o login automaticamente
  • Senhas são armazenadas com hash criptografado (bcrypt)
  • Cada loja é isolada — um lojista não acessa dados de outro (multi-tenant com隔离 total)

Perfis de Usuário

O Sale360 implementa RBAC (Role-Based Access Control) com 4 perfis distintos:

Perfil Acesso Responsabilidades
SUPER ADMIN Todas as lojas Gerencia a plataforma inteira: cria lojas, define planos, gerencia usuários globais e assinaturas
OWNER Sua loja Dono da loja com controle total: produtos, vendas, compras, estoque, clientes, fornecedores, cupons, finanças, indicadores e configurações
STAFF Operação da loja Operador de PDV: realiza vendas, consulta produtos e estoque. Não acessa configurações, finanças ou indicadores
READONLY Leitura apenas Visualiza produtos, vendas, estoque e indicadores. Não pode criar, editar ou excluir nada. Ideal para contadores e auditores
Isolamento por loja: O acesso entre lojas é bloqueado em dois níveis — no middleware de autenticação e nos endpoints de API. Um OWNER da loja A não consegue acessar dados da loja B mesmo conhecendo a URL.
Dica de segurança: Para operadores de caixa, use o perfil STAFF. Ele só acessa o PDV e a lista de produtos — não pode alterar preços, ver relatórios financeiros nem modificar configurações.

Guias Práticos

Esta seção contém tutoriais passo a passo das operações mais comuns do Sale360. Cada guia mostra o fluxo completo — da preparação à conclusão — cruzando diferentes módulos do sistema.

Como Cadastrar Produto e Dar Entrada no Estoque

Objetivo: Ter um produto disponível para venda com estoque físico.
Módulos envolvidos: Fornecedores → Categorias → Produtos → Compras → Estoque
Tempo estimado: 5-8 minutos (primeiro cadastro), 2 minutos (produtos seguintes do mesmo fornecedor)

1. Crie o Fornecedor

O fornecedor é obrigatório para registrar a origem da mercadoria.

1
Acesse o menu Fornecedores No menu lateral, clique em "Fornecedores" (ícone de caminhão).
2
Clique em "Novo Fornecedor" O modal de cadastro será aberto.
3
Preencha os dados do fornecedor Informe ao menos o Nome (obrigatório). CNPJ, telefone, e-mail, endereço e observações são opcionais mas recomendados. Deixe Ativo = Sim.
4
Salve o fornecedor Clique em "Salvar". O fornecedor já fica disponível para compras.
Fornecedor rápido: Se não quiser cadastrar o fornecedor antes, durante a criação da compra você pode marcar a opção "Outros" e digitar apenas o nome. O sistema cria o fornecedor automaticamente.

2. Crie a Categoria (e o Template de Variação se necessário)

Antes de criar o produto, defina em qual categoria ele se encaixa. Se sua loja trabalha com variações (ex: tamanho, cor), configure o template agora.

1
Vá para Produtos e clique em "Categorias" No menu lateral, clique em "Produtos". No topo da página, clique no botão "Categorias". O modal "Gerenciar Categorias" será aberto.
2
Crie uma nova categoria No campo "Nova Categoria", digite o nome (ex: "Bebidas", "Roupas", "Hortifruti").
3
Escolha o Template de Variação (se aplicável) Se os produtos desta categoria têm variações (ex: roupas têm Tamanho e Cor), selecione o template correspondente no dropdown. Opções disponíveis:
  • TAMANHO_LETRA — PP, P, M, G, GG, etc.
  • TAMANHO_NUMERO — 34, 36, 38, 40, 42, etc.
  • COR — Vermelho, Azul, Preto, etc.
  • VOLUME — 200ml, 500ml, 1L, 2L, etc.
  • PESO — 100g, 250g, 500g, 1kg, etc.
  • PERSONALIZADO — Crie suas próprias dimensões
Se o produto não tem variações, deixe em branco.
4
Clique em "Adicionar" A categoria será criada e aparecerá na lista. Feche o modal.

3. Crie o Produto

Agora que você tem fornecedor e categoria, crie o produto.

1
Na tela de Produtos, clique em "Novo" O modal "Novo Produto" será aberto.
2
Preencha os dados básicos
  • Nome* — Nome do produto (ex: "Coca-Cola 2L")
  • SKU — Código interno (se deixar em branco, é gerado automaticamente)
  • Código de Barras — Escaneie ou digite o EAN-13
  • Categoria — Selecione a categoria que você criou
  • Preço de Venda — Preço para o consumidor (R$)
  • Estoque Mínimo — Quantidade para alerta de reposição (ex: 10)
3
Configure as variações (se a categoria tiver template) Após selecionar a categoria, o Editor de Variações aparece automaticamente:
  • Marque as opções desejadas para cada dimensão (ex: Tamanho: M, G, GG / Cor: Azul, Preto)
  • Clique em "Gerar Combinações" — o sistema cria todas as combinações (ex: M+Azul, M+Preto, G+Azul, G+Preto, etc.)
  • Ajuste o Estoque Inicial e Estoque Mínimo de cada variação
4
Clique em "Criar Produto" O produto é criado e já aparece na lista de produtos. Mas atenção: o estoque ainda está zerado — você precisa da compra para dar entrada.
Importante: Criar o produto NÃO gera estoque automaticamente. O estoque só entra no sistema via Compra Recebida ou Ajuste Manual. Siga para o próximo passo.

4. Efetue a Compra dos Produtos

É na compra que você registra quanto pagou e calcula o preço de venda correto.

1
Acesse o menu Compras No menu lateral, clique em "Compras" (ícone de sacola).
2
Clique em "Nova Compra" O modal "Nova Compra" será aberto.
3
Selecione o Fornecedor No dropdown, escolha o fornecedor que você cadastrou. Se ainda não tiver fornecedor, marque a opção "Outros" e digite o nome — o sistema cria na hora.
4
Busque e selecione o produto Digite o nome ou escaneie o código de barras no campo de busca. Clique no produto encontrado.
5
Preencha a Calculadora de Precificação (5 campos) A calculadora aparece ao selecionar o produto:
CampoO que éExemplo
Custo Un.Preço pago ao fornecedor por unidadeR$ 5,00
Custo Oper.Embalagem, frete, armazenamento por unidadeR$ 0,50
Taxa %Taxa da máquina de cartão (%)3%
Margem %Porcentagem de lucro desejada50%
Pr. VendaPreço final calculado (ou defina manualmente)R$ 8,25

Fórmula: Preço Venda = (Custo + Custo Operacional) ÷ (1 - Taxa/100) × (1 + Margem/100)
Dica: Você pode digitar o Preço de Venda diretamente e o sistema recalcula a Margem automaticamente.

6
Informe a quantidade e adicione à compra Digite a quantidade comprada (para produtos com variação, informe a quantidade de cada variação). Clique em "Adicionar à Compra".
7
Repita para mais produtos (se necessário) e finalize Adicione todos os produtos do pedido. Se houver um desconto geral do fornecedor, preencha o campo Desconto (R$). Depois clique em "Criar Compra (R$ ...)".

5. Receba a Compra (Entrada no Estoque)

A compra foi criada como Rascunho. Para o estoque ser atualizado, você precisa "Receber" a compra.

1
Na lista de Compras, localize a compra em Rascunho Compras com status "Rascunho" exibem um ícone de checkmark (✓) verde.
2
Clique no ícone ✓ para Receber O modal "Confirmar Recebimento" será aberto mostrando todos os itens.
3
Informe a data de validade (se aplicável) Para produtos perecíveis (alimentos, bebidas, etc.), informe a data de validade de cada lote. O sistema usa isso para alertas de vencimento.
4
Clique em "Confirmar Recebimento" Pronto! O estoque é atualizado:
  • Lotes de estoque são criados (método PEPS)
  • A quantidade em estoque do produto é atualizada
  • O preço de venda do produto é atualizado com base na precificação

6. Verifique o Estoque

Vá ao menu "Estoque" (ícone de camadas) e confira se o produto aparece com o saldo correto. Na aba "Lotes" você vê cada entrada separada com data, quantidade e custo.

Cuidado: Uma compra Recebida não pode ser editada. Se houver erro nos valores, cancele a compra e crie uma nova com os dados corretos.
Resumo do fluxo completo: Fornecedor → Categoria (+ template) → Produto → Compra (com precificação) → Receber Compra → Estoque disponível para venda.

Como Realizar uma Venda Completa no PDV

Objetivo: Registrar uma venda no PDV, do cliente ao pagamento.
Módulos envolvidos: Vendas (PDV) → Clientes → Cupons → Estoque
Tempo estimado: 30-60 segundos (venda típica de balcão)

1. Abra a Tela de Vendas

1
No menu lateral, clique em "Vendas" É o ícone de carrinho de compras. Você verá o histórico de vendas anteriores.
2
Clique em "Nova Venda" O modal "Nova Venda" será aberto. Para operação contínua de caixa, use o botão "PDV Tela Cheia" que otimiza a interface para uso em monitor ou tablet.

2. Selecione o Cliente (ou Use Consumidor Final)

1
Busque um cliente cadastrado Digite o nome, telefone ou CPF no campo de busca. Se encontrar, clique no cliente para associá-lo à venda.
2
Ou use "Nome avulso" para consumidor final Para vendas de balcão sem cadastro, clique em "Nome avulso" e digite um nome qualquer (ou deixe como "Consumidor Final"). Não é obrigatório ter cliente cadastrado para vender.

3. Adicione Produtos ao Carrinho

1
Busque o produto Digite o nome, SKU ou escaneie o código de barras no campo de busca. A grade de produtos também está disponível para seleção visual.
2
Clique no produto desejado Uma ficha rápida (QuickAddSheet) aparece para você:
  • Ajustar a quantidade
  • Selecionar a variação (se o produto tiver variações)
  • Para produtos com lotes e validade, o sistema pré-seleciona o lote mais antigo (PEPS)
3
Confirme a adição O item aparece no carrinho. Repita para adicionar mais produtos.

4. Aplique Descontos e Cupons (Opcional)

1
Desconto manual (R$) No campo "Desconto (R$)" do carrinho, digite um valor em reais para abater do total.
2
Cupom de desconto Se o cliente tiver um código promocional, digite no campo "Cupom de desconto" e clique em "Aplicar". O sistema valida automaticamente se o cupom está ativo, dentro do prazo e se a compra atinge o valor mínimo.

5. Selecione a Forma de Pagamento

Cinco opções de pagamento:

FormaQuando usar
DinheiroPagamento em espécie. Informe o valor recebido para calcular o troco.
PixPagamento instantâneo via Pix. Opcionalmente gere QR code.
DébitoCartão de débito. Registre os últimos 4 dígitos se desejar.
CréditoCartão de crédito. Pode parcelar conforme política da loja.
FiadoVenda a prazo. Exige data de vencimento. O cliente deve ter cadastro.
Pagamento Misto: O Sale360 suporta combinar duas ou mais formas de pagamento na mesma venda. Ex: R$ 50 em dinheiro + R$ 30 no Pix.

6. Finalize a Venda

1
Confira o resumo Verifique os itens, quantidades, subtotal, desconto, cupom e total final.
2
Clique em "Finalizar Venda (R$ ...)" A venda é concluída! O estoque é baixado automaticamente (consumindo os lotes mais antigos — PEPS).

7. Ações Pós-Venda

  • Cancelar venda: Na lista de vendas, clique no pedido e use a opção "Cancelar". O estoque é revertido automaticamente para os lotes originais.
  • Confirmar pagamento de fiado: Vendas fiado ficam com status "Pendente". Quando o cliente pagar, acesse a venda e clique em "Confirmar Pagamento".
  • Enviar cobrança WhatsApp: Para vendas fiado, há a opção de enviar um lembrete de cobrança diretamente pelo WhatsApp do cliente.
  • Visualizar detalhes: Clique em qualquer venda no histórico para ver itens, valores, descontos e dados do pagamento.
Atenção: O cancelamento de venda é irreversível. O estoque volta automaticamente, mas o registro não pode ser desfeito. Confirme antes de cancelar.

Como Gerenciar Vendas Fiado (a Prazo)

Objetivo: Vender a prazo, controlar o crédito do cliente e receber depois.
Módulos envolvidos: Clientes → Vendas → Financeiro

1. Cadastre o Cliente (se ainda não tiver)

1
Acesse o menu Clientes Clique em "Clientes" no menu lateral.
2
Clique em "Novo Cliente" Preencha nome, telefone (WhatsApp) e CPF. O telefone é importante para enviar cobranças depois.
3
Salve o cliente O cliente fica disponível para vendas e começa com saldo devedor zerado.

2. Realize a Venda Fiado

1
Abra "Nova Venda" no menu Vendas
2
Selecione o cliente cadastrado Busque pelo nome ou telefone. O fiado só está disponível para clientes com cadastro.
3
Adicione os produtos ao carrinho Siga o fluxo normal de adição de produtos.
4
Selecione "Fiado" como forma de pagamento Ao escolher Fiado, o campo "Data de Vencimento" aparece. Selecione a data combinada com o cliente.
5
Finalize a venda A venda fica com status "Pendente" e o valor é lançado no crédito do cliente.

3. Acompanhe e Receba o Pagamento

1
Monitore as vendas pendentes No menu "Financeiro", a seção de "Recebíveis Pendentes" mostra todas as vendas fiado em aberto.
2
Envie cobrança via WhatsApp No detalhe da venda, use a opção de envio de mensagem de cobrança. O WhatsApp abre com a mensagem pré-preenchida.
3
Quando o cliente pagar, confirme o recebimento Acesse a venda no histórico e clique em "Confirmar Pagamento". O status muda para "Pago".
Controle de crédito: Fique atento ao saldo devedor de cada cliente nos detalhes do cadastro. O sistema exibe o total devido e o histórico completo de transações de crédito.

Como Configurar e Compartilhar seu Catálogo Online

Objetivo: Ter uma vitrine online onde clientes veem seus produtos e compram via WhatsApp.
Módulos envolvidos: Configurações → Produtos → Catálogo Online

1. Configure os Dados da Loja

1
Acesse Configurações → aba Catálogo No menu lateral, clique em "Config" e depois na aba "Catálogo".
2
Preencha as informações da loja
  • Nome da Loja — Aparece no topo do catálogo
  • Telefone (WhatsApp) — Número que o cliente chama ao clicar em "Comprar"
  • Endereço — Endereço físico da loja (opcional)
  • Logo — Imagem da sua marca (aparece no topo do catálogo)
  • Cores — Personalize as cores do catálogo com sua identidade visual
3
Configure os banners Adicione imagens de destaque no topo do catálogo (promoções, novidades, etc.).
4
Configure os métodos de pagamento aceitos Marque quais formas de pagamento aparecem no catálogo (Pix, Dinheiro, Cartão, etc.). Você pode adicionar instruções para cada uma.
5
Defina o comportamento de produtos sem estoque Escolha entre Esconder (some do catálogo) ou Mostrar (aparece mas com aviso de indisponível).
6
Salve as configurações

2. Prepare os Produtos

Certifique-se de que os produtos que você quer exibir estão:

  • Com o campo Ativo = Sim (produtos inativos não aparecem)
  • Com fotos cadastradas (produtos com imagem atraem mais cliques)
  • Com preço de venda definido

3. Compartilhe o Link

1
Copie o link do seu catálogo O formato é: https://sualoja.jvptecnologia.com.br/c/seu-slug. O link aparece nas configurações do catálogo.
2
Compartilhe nos seus canais
  • Instagram Bio (link direto)
  • Stories do Instagram e Facebook
  • WhatsApp Business (mensagem de saudação)
  • Google Meu Negócio
  • Grupos de WhatsApp e Telegram

4. Como o Cliente Compra

O fluxo para o cliente é simples:

  1. Acessa o link do catálogo
  2. Navega pelos produtos, busca por nome ou categoria
  3. Clica em "Comprar" no produto desejado
  4. O WhatsApp abre automaticamente com uma mensagem pronta: "Olá! Tenho interesse no produto [Nome do Produto] - [Link]"
  5. Você combina pagamento e entrega pelo WhatsApp
  6. Registre a venda normalmente no PDV do Sale360
Dica de ouro: Coloque o link do catálogo na bio do Instagram e na saudação automática do WhatsApp Business. É a vitrine online mais simples e eficaz para começar a vender hoje.

Como Importar Dados em Massa (CSV)

Objetivo: Cadastrar dezenas ou centenas de produtos, fornecedores ou compras de uma só vez.
Disponível nos planos: GROW e PRIME
Tempo estimado: 5-10 minutos

1. Baixe o Template CSV

1
Acesse a página de Importação No menu lateral, clique no link "Guia de Importação" (disponível na tela de Produtos ou Compras).
2
Baixe o template adequado Escolha entre:
  • Produtos Simples — Produtos sem variação
  • Produtos com Variações — Produtos com tamanho, cor, etc.
  • Categorias — Categorias com ou sem template de variação
  • Fornecedores — Cadastro de fornecedores
  • Compras — Compras com precificação completa
O arquivo CSV contém cabeçalhos explicativos.

2. Preencha o Arquivo

1
Abra o CSV no Excel, Google Sheets ou LibreOffice Mantenha a primeira linha com os cabeçalhos intacta.
2
Preencha uma linha por item Siga as instruções do Guia de Importação para cada campo:
  • Campos obrigatórios — Não deixe em branco
  • Categorias — Se a categoria não existir, o sistema a cria automaticamente
  • Variações — Use o formato: "Tamanho: P, M, G | Cor: Azul, Vermelho"
3
Salve o arquivo como CSV (UTF-8) No Excel: "Arquivo → Salvar Como → CSV UTF-8". Evite acentos e caracteres especiais fora do padrão.

3. Importe o Arquivo

1
Use o botão "Importar" na tela correspondente Ex: Para importar produtos, vá em Produtos → Importar.
2
Selecione o arquivo CSV O sistema lê o arquivo e valida cada linha antes de importar.
3
Revise os resultados da validação O sistema exibe:
  • Total de linhas encontradas
  • Linhas com erro e a descrição do problema
  • Linhas que serão importadas com sucesso
Corrija os erros no arquivo e reenvie se necessário.
4
Confirme a importação Clique em "Importar". Os dados são inseridos em lote.
Atenção: A importação de Compras cria os pedidos como Rascunho. Você ainda precisa "Receber" cada compra para dar entrada no estoque.
Faça um teste antes: Importe apenas 2 ou 3 itens primeiro para validar o formato. Depois de confirmar que está tudo certo, importe o arquivo completo.

Primeira Configuração da Loja

Objetivo: Deixar sua loja pronta para operar — da configuração básica à primeira venda.
Público: Dono da loja (OWNER) no primeiro acesso.
Tempo estimado: 15-20 minutos

1. Faça o Login e Troque a Senha

1

PDV (Ponto de Venda)

O módulo de PDV é o coração do Sale360. Ele permite realizar vendas de forma rápida e gerenciar todo o histórico.

Histórico de Vendas

A tela principal de Vendas exibe todas as transações com:

  • Número do pedido — Identificador sequencial único
  • Cliente — Nome do cliente (opcional na venda rápida)
  • Valor total — Com desconto aplicado
  • Data e hora — Momento exato da venda
  • Status — Concluído, Cancelado, Pendente
  • Forma de pagamento — Dinheiro, Cartão, Pix, Misto

Ao expandir uma venda, você visualiza todos os itens, quantidades, preços unitários e descontos aplicados.

Nova Venda — Modal Rápido

Para abrir uma nova venda, clique no botão "Nova Venda". O modal rápido permite:

  1. Buscar produto — Digite o nome ou código do produto. A busca é instantânea.
  2. Adicionar ao carrinho — Clique no produto, ajuste a quantidade se necessário
  3. Revisar carrinho — Itens, quantidades, subtotal e total são exibidos em tempo real
  4. Aplicar desconto — Desconto em reais (R$) ou porcentagem (%) sobre o total
  5. Selecionar pagamento — Escolha a forma de pagamento
  6. Finalizar — Um clique para concluir a venda
Venda rápida sem cliente: Não é obrigatório selecionar um cliente. Para vendas de balcão, basta adicionar os produtos e finalizar — o sistema registra como "Consumidor Final".

Tela de PDV Completa (Tela Cheia)

O modo PDV Tela Cheia foi projetado para uso em caixa com monitor ou tablet. Ele oferece:

  • Busca em destaque — Campo de busca grande e central para agilidade
  • Grade de produtos — Visualização em grid com fotos para seleção rápida
  • Carrinho lateral — Sempre visível com subtotal, desconto e total
  • Atalhos de teclado — Navegação e finalização sem mouse
  • Modo contínuo — Ao finalizar uma venda, o PDV já está pronto para a próxima

Cancelamento de Venda

Uma venda pode ser cancelada a qualquer momento. Ao cancelar:

  • O estoque é automaticamente revertido (itens voltam para os lotes originais)
  • O status muda para CANCELADO
  • O motivo do cancelamento é registrado para auditoria
  • Vendas canceladas não aparecem nos indicadores de faturamento
Atenção: O cancelamento de venda é irreversível e restaura o estoque automaticamente. Certifique-se antes de confirmar.

Variações de Produto

Produtos podem ter variações (ex: tamanho, cor, sabor). Cada variação possui:

  • Nome — Identificador da variação (ex: "500ml", "1L", "2L")
  • SKU próprio — Código único por variação
  • Preço independente — Cada variação pode ter preço diferente
  • Estoque separado — Controle de quantidade por variação
  • Código de barras — EAN-13 para leitura por scanner
Produto sem variação: Se o produto não tiver variações, o sistema trata como uma variação padrão automaticamente. O fluxo de venda e estoque funciona da mesma forma.

É possível importar produtos via arquivo CSV. O formato esperado inclui: nome, SKU, categoria, preço de venda, custo, estoque inicial e unidade. O sistema valida cada linha e reporta erros antes de inserir.

Estoque

O módulo de Estoque oferece controle completo do inventário com rastreamento por lote usando o método PEPS (Primeiro que Entra, Primeiro que Sai).

Visão Geral

A tela principal do estoque exibe:

  • Produto — Nome, SKU e categoria
  • Saldo Atual — Quantidade disponível para venda
  • Custo Médio — Custo médio ponderado de todas as compras
  • Último Custo — Custo da compra mais recente
  • Valor Total — Saldo × Custo médio (valor do estoque em R$)
  • Alerta — Indicador visual quando o estoque está abaixo do mínimo

Lotes de Estoque (PEPS)

Cada entrada de estoque (via Compra) gera um lote com:

  • Data de recebimento — Quando a mercadoria entrou no estoque
  • Quantidade original — Quantidade recebida na compra
  • Saldo disponível — O que resta deste lote (diminui com as vendas)
  • Custo unitário — Preço pago nesta compra específica

Quando uma venda é realizada, o sistema automaticamente:

  1. Consome primeiro os itens do lote mais antigo (PEPS)
  2. Passa para o próximo lote se o primeiro não tiver saldo suficiente
  3. Registra o custo real da mercadoria vendida (CMV) baseado no lote
Lucro real por venda: Como o Sale360 rastreia o custo exato de cada item vendido via PEPS, o indicador de margem de lucro reflete o valor real — não uma estimativa baseada em custo médio.

Entradas e Saídas

O estoque é movimentado de duas formas:

  • Entrada: Ao Receber uma compra, os itens entram no estoque como novos lotes
  • Saída: Ao Finalizar uma venda, os itens saem do estoque consumindo os lotes mais antigos
  • Ajuste manual: Correções de inventário podem ser feitas diretamente na tela de estoque (com registro de motivo)
Compras em Rascunho NÃO afetam estoque: Uma compra só entra no estoque quando seu status é alterado para "Recebido". Enquanto estiver em Rascunho, não há movimentação de estoque.

Compras

O módulo de Compras gerencia todo o processo de aquisição de mercadorias, desde o pedido até a entrada no estoque.

Fluxo da Compra

📝 Rascunho → ✅ Recebido ou ✕ Cancelado

Uma compra sempre começa como Rascunho (DRAFT). A partir daí, pode ser Recebida (entra no estoque) ou Cancelada (não afeta estoque).

Criar / Editar Compra

Para criar uma compra:

  1. Selecione o Fornecedor
  2. Adicione os Itens (produtos, quantidades e custos unitários)
  3. Opcional: Vincule um Cliente (para encomendas sob demanda)
  4. Adicione Observações se necessário
  5. Salve como Rascunho

Calculadora de Precificação (5 Campos)

O Sale360 oferece uma calculadora de preço de venda com 5 variáveis para cada item da compra:

CampoDescrição
Custo UnitárioPreço pago ao fornecedor por unidade
Custo OperacionalEmbalagem, frete, armazenamento (R$ por unidade)
Taxa Cartão (%)Percentual da taxa da máquina de cartão
Margem (%)Margem de lucro desejada sobre o custo total
Preço de VendaCalculado automaticamente ou definido manualmente
Fórmula: Preço Venda = (Custo + Custo Operacional) ÷ (1 - Taxa Cartão/100) × (1 + Margem/100). Todos os campos são editáveis — alterar qualquer um recalcula os dependentes.

Recebimento de Compra

Ao receber uma compra:

  • O status muda de Rascunho → Recebido
  • Novos lotes de estoque são criados para cada item
  • A data de recebimento é registrada (usada na ordenação PEPS)
  • Datas de validade podem ser informadas por lote (para produtos perecíveis)
  • O preço de venda do produto pode ser atualizado automaticamente com base na precificação

Importação de Compras via CSV

Compras podem ser importadas em lote via arquivo CSV. O template inclui: fornecedor, produto, quantidade, custo unitário, custo operacional, taxa cartão, margem e preço de venda sugerido.

Atenção: Uma compra Recebida não pode ser editada. Para corrigir um erro, cancele a compra e crie uma nova com os dados corretos.

Como Instalar

1
Acesse o Sale360 pelo navegador do celular Abra o Chrome ou Safari e acesse a URL da sua loja.
